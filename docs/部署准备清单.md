# QAFlow 部署准备清单

这份清单用于正式部署前做准备。当前你还没有购买服务器和域名，所以先按“购买前准备”和“购买后配置”两步走，不需要一上来就进入复杂部署。

## 1. 推荐部署目标

第一阶段建议先部署一个“作品展示 + 自用验证”版本：

- 支持账号登录、测试资产管理、APP 自动化配置、AI 探索报告、数据工厂页面访问。
- 先不把真实公司测试环境地址、真实账号、真实机器人 Webhook 写进代码仓库。
- APP 真机自动化、ADB、Airtest 这类能力可以后置，因为云服务器通常没有直连手机环境。

## 2. 购买服务器前需要确认

### 2.1 云服务商

任选一个即可：

- 阿里云、腾讯云、华为云：国内访问稳定，但域名备案会更麻烦。
- 香港/新加坡云服务器：不用备案，部署更快，适合作品展示。
- 自建小主机/NAS：成本可控，但外网访问、网络稳定性和安全配置需要自己处理。

### 2.2 服务器配置

推荐最低配置：

- CPU：2 核
- 内存：4 GB
- 硬盘：40 GB SSD
- 系统：Ubuntu 22.04 LTS
- 带宽：2 Mbps 起步，作品展示够用

更稳妥配置：

- CPU：2 核或 4 核
- 内存：8 GB
- 硬盘：80 GB SSD
- 带宽：5 Mbps

### 2.3 域名

可以先不买域名，直接用服务器公网 IP 验证部署。

如果要买，建议：

- 域名尽量短，方便面试展示。
- 可以使用 `qaflow.cn`、`qaflow-test.com`、`yourname-qaflow.com` 这类命名。
- 国内服务器绑定域名通常需要备案；海外/香港服务器一般不需要备案。

### 2.4 是否需要 HTTPS

建议需要。原因：

- 登录态 Cookie、接口请求更安全。
- 面试展示看起来更完整。
- 后续机器人回调、第三方集成更标准。

可以使用 Nginx + Certbot 免费申请 Let's Encrypt 证书。

## 3. 购买服务器后需要准备

### 3.1 基础软件

服务器需要安装：

- Git
- Python 3.12
- Node.js 20 LTS
- MySQL 8.0
- Redis 6+
- Nginx
- Java 17，用于 Allure 报告

### 3.2 项目配置

服务器上需要创建 `.env` 文件，至少配置：

```env
DEBUG=False
SECRET_KEY=replace-with-a-random-secret
ALLOWED_HOSTS=your-domain.com,your-server-ip
CSRF_TRUSTED_ORIGINS=https://your-domain.com

DB_NAME=qaflow
DB_USER=qaflow
DB_PASSWORD=replace-with-db-password
DB_HOST=127.0.0.1
DB_PORT=3306

REDIS_URL=redis://127.0.0.1:6379/0
```

如果后续要接 AI、企微、飞书，再单独增加：

```env
OPENAI_API_KEY=your-api-key
OPENAI_BASE_URL=https://your-model-provider.example.com/v1

WECOM_WEBHOOK_URL=your-wecom-webhook-url
FEISHU_WEBHOOK_URL=your-feishu-webhook-url
```

这些值只放服务器 `.env`，不要提交到 GitHub。

### 3.3 安全配置

上线前至少要做：

- 修改服务器 root 密码，或改用 SSH key 登录。
- 安全组只开放 `22`、`80`、`443`。
- 数据库和 Redis 不要开放公网端口。
- `.env`、日志、上传文件不要提交到 Git。
- GitHub 仓库建议先保持 Private，脱敏稳定后再考虑 Public。

## 4. 部署方式建议

第一阶段建议使用普通 Linux 部署：

- 后端：Django + Daphne/Gunicorn + systemd
- 前端：Vue build 后由 Nginx 托管
- 队列：Celery + Redis
- 数据库：MySQL
- 网关：Nginx 反向代理 `/api/`、`/ws/`、`/media/`

不建议第一阶段直接 Docker 化。Docker 后期可以补，但现在目标是尽快完成可访问、可演示、可讲清楚的版本。

## 5. 部署前本地检查

每次准备发版前，先在本地执行：

```powershell
.\venv\Scripts\python.exe manage.py check
.\venv\Scripts\python.exe manage.py test apps.data_factory apps.app_automation.tests.test_device_touch_capture apps.app_automation.tests.test_recording_manager --keepdb --verbosity 1

cd frontend
npm run lint
npm run build
```

通过后再提交和部署。

## 6. 下一步行动

你现在最适合先做三件事：

1. 购买一台 Ubuntu 22.04 服务器，优先选 2 核 4 GB 或 2 核 8 GB。
2. 先不买域名，用公网 IP 完成第一版部署验证。
3. 部署成功后，再决定是否购买域名并开启 HTTPS。
